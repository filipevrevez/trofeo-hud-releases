trofeohud

A macOS desk HUD for the Thermalright Trofeo Vision 11.3" LCD (1920×440). Thermalright only ships Windows software; this drives the panel from your Mac.

Download for Mac (Apple Silicon)

What it shows

  • Claude Code: session and weekly limits, today's cost and tokens
  • Orca agents: working, waiting and done panes
  • Now Playing from any app: Spotify, Apple Music/TV, YouTube in a browser…
  • Clock, weather, calendar and Mac stats (CPU, CPU temperature, RAM)

Install

Open the DMG and drag Trofeo HUD to Applications. The app isn't notarised yet, so clear the quarantine flag once:

xattr -dr com.apple.quarantine "/Applications/Trofeo HUD.app"

It lives in the menu bar. Quit TRCC first: only one app can hold the panel. On first run, allow Keychain access to "Claude Code-credentials" (usage limits). After that the app keeps itself up to date.

Layouts

Menu bar → Edit Layouts…. A layout is up to five columns, each a widget. Drag the dividers to resize, pick an icon for its Stream Deck key, and click the screen icon next to a layout to put it on the HUD. Mounted upside down? Settings → Display.

Stream Deck

Stream Deck → Install plugin, then accept the plugin and its profile in the Elgato app. Layout keys show each layout's name and icon and light up when it's on the HUD. There are also Previous/Next layout, Screen on/off and media keys.

Configuration

Settings → Edit config file sets the weather location, calendar feeds (iCal URLs), night mode and frame rate. Restart the HUD from the menu bar after editing.

Troubleshooting

  • Panel won't connect: quit TRCC or any other app using the panel. Logs: Settings → Open logs.
  • Empty cost/tokens: npx ccusage must work in a terminal (Node installed).
  • "nothing playing": the player must show up in Control Center's Now Playing.
