# Trofeo HUD — releases

Downloads, docs and the auto-update feed for **Trofeo HUD**, a macOS desk HUD
for the Thermalright Trofeo Vision 11.3" LCD (1920×440): Claude Code usage,
Orca agents, Now Playing from any app, clock, weather, calendar and Mac stats,
with layouts you design yourself and Stream Deck keys.

- **Download:** [latest release](https://github.com/filipevrevez/trofeo-hud-releases/releases/latest) (`Trofeo-HUD-x.y.z.dmg`, Apple Silicon, macOS 13+)
- **Docs:** https://filipevrevez.github.io/trofeo-hud-releases/

The app updates itself from `latest.json` in this repo (served by GitHub Pages).
Source lives in a private repository.
